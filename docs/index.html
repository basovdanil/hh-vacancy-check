Демо · hh-vacancy-check

Открыта ли вакансия на hh.ru

hh держит страницу закрытой вакансии в сети, а в шаблоне любой карточки стоит «Вакансия в архиве» — поэтому поиск по тексту врёт в обе стороны. Инструмент читает дедлайн работодателя из блока schema.org JobPosting и отвечает OPEN, CLOSED или UNKNOWN.

Проверить вакансию по id или ссылке

Или разобрать страницу у себя в браузере

Браузер на этой странице не может сам запросить hh.ru: сайт не отдаёт CORS-заголовки, и любой прямой запрос из чужого домена блокируется. Поэтому второй путь — открыть вакансию, нажать Ctrl+U (исходный код), Ctrl+A, Ctrl+C и вставить сюда: разбор идёт ровно тем же правилом, что в CLI.

Как проверить любую вакансию

python vacancy_check.py 139441388 139528682
python vacancy_check.py https://hh.ru/vacancy/139441388 --json

Один файл, только стандартная библиотека, Python 3.8+. Код возврата 0 — все открыты, 4 — есть закрытые, 3 — страницу не удалось получить.

Снимок на странице собирается тем же скриптом раз в неделю (GitHub Actions) и хранится в docs/data.json. Если вакансии нет в снимке — используйте CLI или разбор исходника выше.
